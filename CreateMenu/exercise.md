# Menu Exercise — Build Your Own Menu

## Goal

Create a working navigation menu for a small website. The menu should look good on desktop and stack on mobile. Add hover and focus styles so keyboard users can see which link is active.

## What to open

- `starter.html` — a starter file with a simple page structure.
- `style.css` — the stylesheet used by the demo. You can edit it or create a new CSS file.

## Tasks

1. Open `starter.html` in the browser (or `index.html` to see the example).
2. Inside the `nav` element, add at least four links (`Home`, `About`, `Services`, `Contact`).
3. In `style.css`, make the list horizontal using `display: flex` on the `ul`.
4. Style the links with padding, background color, and rounded corners.
5. Add `:hover` and `:focus` styles so the links change color or background when hovered or focused.
6. Use a media query to stack the menu vertically at small widths (e.g., 520px).

## Stretch Goals (optional)

- Add an `active` class to highlight the current page.
- Create a dropdown submenu for one item.
- Add CSS variables for colors and let classmates pick a theme.

## Submission / Checklist

- [ ] HTML contains a `nav` with an unordered list of links.
- [ ] Links are styled and have hover/focus states.
- [ ] Menu stacks on narrow screens.

When finished, open your page locally and test the tab key to confirm focus styles.
