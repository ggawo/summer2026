# 🚀 Summer Teen Coding Class: Intro to Web Development

Welcome to the **Summer Teen Coding Class** repository!

This repository contains all the course materials, weekly code templates, project starter files, and reference guides used throughout our hands-on Web Development course designed for ages 12–18.

Whether you're building your very first web page or refining your interactive scripts, everything you need is right here!

---

## 📚 What We're Learning

In this course, we move from the fundamentals of structural markup to interactive programming:

- **HTML5:** The skeleton of the web—structuring content, headings, forms, and media.
- **CSS3:** Styling and design—colors, typography, layout models (Flexbox & Grid), and responsive design.
- **JavaScript (JS):** Bringing pages to life—variables, functions, DOM manipulation, and interactive events.
