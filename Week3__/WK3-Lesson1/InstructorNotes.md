# Instructor Notes: Week 3, Session 1

## Key Concept to Anchor
Students will initially struggle to remember which properties affect the parent container versus the child items[cite: 30]. Reinforce the concept of the **Parent Control Center**[cite: 30]. Tell them: `display: flex`, `justify-content`, and `align-items` must *only* be typed into the rule block for the parent wrapper container[cite: 30]. 

## Pro-Tip for Visual Troubleshooting
If students state that `align-items: center;` isn't centering their content vertically, it is almost always because the parent box has no height context[cite: 30]! Remind them that containers default to the height of their content[cite: 30]. Give the parent box a fixed height value (like `height: 200px;`) so the browser has room to slide items up and down[cite: 30].
