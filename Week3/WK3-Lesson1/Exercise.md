# Exercise 5: Building a Social Media Profiler Header Navbar

## Core Challenge (Level 1)
Build a fully operational website navigation header bar (Navbar) where logo assets and navigation target items stay cleanly distributed across horizontal screens using Flexbox layouts[cite: 29].

### Step-by-Step Instructions
1. Create `navbar.html` and `style.css` in a fresh workspace folder[cite: 29].
2. Build an outer structural wrapper `<nav class="navbar">`. Inside it, place a Logo `div` element and an inner Link Group box container[cite: 29].
3. Turn the main parent navbar container into a flex layout context (`display: flex;`)[cite: 29].
4. Apply the correct `justify-content` strategy so that the logo remains locked on the far left edge and navigation element targets sit balanced on the far right edge[cite: 29].
5. Vertically center the alignment of items so text tags look perfectly aligned regardless of different box sizes[cite: 29].
