# Instructor Notes: Week 3, Session 2

## Advanced Concept Extension
Explain that `flex-direction: column;` flips the main and cross layout tracking axes[cite: 27]. When a container switches to `column`, `justify-content` now aligns items **vertically** up and down, while `align-items` now controls alignment **horizontally** left and right[cite: 27]! This will be a classic "aha!" moment for the kids when they experiment with layout orientation swaps[cite: 27].
