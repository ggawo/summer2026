# Exercise 1: Building a Profile Hub

## Core Challenge (Level 1)
Create an HTML page from scratch that functions as a profile hub for a topic you love (a World Cup national team, a favorite sports franchise, a video game, or yourself). 

### Step-by-Step Instructions
1. Open VS Code and create a new file named `my_profile.html`.
2. Type out the required skeleton structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
3. Set the `<title>` inside your head to match your chosen topic.
4. Inside the `<body>`, use an `<h1>` for the main title of your hub.
5. Create at least **two separate sections** using `<h2>` tags.
6. Write at least **four paragraphs (`<p>`)** distributed across your sections to describe the details.
7. Save your work (`Ctrl+S` or `Cmd+S`) and open it in a browser to check your layouts.

---

## Intermediate Challenge (Level 2)
Add hierarchy to your data using deep heading structures.
* Under one of your `<h2>` tags, create two sub-sections using `<h3>` tags.
* Add a tiny, fine-print disclaimer or update notice at the absolute bottom of the page using an `<h6>` tag.

---

## Extreme Challenge (Level 3 - Fast Finishers)
Browsers automatically skip lines and add spacing between block elements like headings and paragraphs. 
1. Research or experiment with the `<br>` tag (Break tag) and the `<hr>` tag (Horizontal Rule tag).
2. Discover how they differ from text tags: Do they require a closing tag (`</br>` or `</hr>`)? 
3. Use an `<hr>` to draw a visual divider line separating your main profile content from your `<h6>` footer content.
