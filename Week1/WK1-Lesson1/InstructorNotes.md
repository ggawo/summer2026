# Instructor Notes: Week 1, Session 1

## Time Management Guide
* **00:00 - 00:15:** Welcome, icebreaker, and the Restaurant Analogy. Keep it engaging—ask them what happens if the waiter drops the plate (Server Error!).
* **00:15 - 00:30:** Live Coding Demo. Open a blank window in VS Code, write the shell, create a mistake (e.g., `<p>Text`, forgetting the closing tag), and show how the browser tries to guess the ending but behaves unexpectedly.
* **00:30 - 00:52:** Student Exercise Lab. Walk the floor constantly. 
* **00:52 - 01:00:** Review the Extreme Challenge. Have a student who successfully figured out the `<hr>` tag explain what it did to their page. Preview the next session (adding links, visual styling, and images).

## Classroom Management Strategy for Teens
* **The Wide-Gap Range:** 12-year-olds might struggle to find key symbols on the keyboard (`<`, `>`, `/`), while 18-year-olds might finish the standard project in 5 minutes. Use the Level 3 Extreme Challenge specifically to keep the older/faster students fully engaged while you provide hands-on help to younger students.
* **Keyboard Shortcut Drill:** Force them to learn `Ctrl+S` (Windows) / `Cmd+S` (Mac) right away. Call it out like a reflex whenever they modify code.

## Troubleshooting Quick-Fix List
1. **The Extension Issue:** If a student opens a file in Chrome and sees raw text codes (`<html><h1>...`) instead of rendered elements, they saved it as a `.txt` file or named it `project.html.txt`. Have them select "Save As" in VS Code and verify the dropdown is set to All Files or HTML.
2. **Missing Tags:** If half the text on a student's screen is giant and bold, they left an `<h1>` open somewhere above it. Teach them to look back up their code to find the missing `/`.
