# Exercise 4: Building a Tournament Scoreboard Display

## Core Challenge (Level 1)
Build a responsive visual leaderboard/scoreboard layout using custom box-model spacing configurations. 

### Step-by-Step Instructions
1. Create `scoreboard.html` and `style.css` in your project folder.
2. Build 3 separate card components containing team scoring metrics (e.g., Team Name, Group, Goals Scored).
3. Apply a distinct background color and border element framework to each card.
4. Add internal padding to make the text clean and highly readable.
5. Apply external margins to create even vertical gaps between each card down the screen.

---

## Intermediate Challenge (Level 2)
1. Use the individual side selectors (`margin-top`, `padding-left`) to create custom asymmetrical cards.
2. Set a definitive `width` configuration on your cards (like `400px`) and center them perfectly on the page using `margin: 0 auto;`.
3. Give your cards a subtle drop shadow effect using the `box-shadow` property (e.g., `box-shadow: 2px 4px 10px rgba(0,0,0,0.1);`).

---

## Extreme Challenge (Level 3 - Fast Finishers)
1. Add an interactive `hover` effect onto your scoreboard cards. 
2. Use the CSS pseudo-class selector rule `.team-card:hover { ... }`.
3. When hovered, change the background color or shift the card up slightly by altering its margins or using a small box-shadow glow enhancement.
